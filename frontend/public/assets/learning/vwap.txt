VWAP

1. What is VWAP?

VWAP (Volume Weighted Average Price) is a dynamic indicator that shows the average price of a security, weighted by traded volume, over a given period.

Formula: VWAPt=∑(Pricei×Volumei)∑VolumeiVWAP_t = \frac{\sum (Price_i \times Volume_i)}{\sum Volume_i}

It represents the “true fair value” where most trading happened, unlike a simple moving average which only uses price.

2. Who Invented VWAP?

VWAP was introduced in 1984 by James A. Abbot and Peter Steidlmayer (CME traders).

It was first used by institutions as an execution benchmark:

If they bought below VWAP, they did better than the “average buyer.”

If they sold above VWAP, they did better than the “average seller.”

Over time, traders adopted VWAP as a technical indicator for intraday trend, mean reversion, and institutional footprints.

3. Why VWAP Matters

For Institutions: Benchmark to judge order execution.

For Retail Traders: Helps identify trend bias, support/resistance, liquidity zones.

For Options Traders: Serves as magnet or polarity zone where price often gravitates intraday.

VWAP = bridge between retail psychology and institutional flow.

4. Types of VWAP

🔹 1. Standard Daily VWAP

Resets each day at market open.

Most common for intraday scalping & option expiry plays.

🔹 2. Anchored VWAP (AVWAP)

Trader chooses the starting “anchor point.”

Useful for swing & positional trades.

Anchor to:

Swing high/low

Gap day

Event candle (earnings, news, Fed day)

Monthly/Yearly open

🔹 3. Rolling VWAP

VWAP applied over rolling windows (5D, 20D, etc).

Like a VWAP-based moving average.

Shows longer-term institutional value drift.

🔹 4. Higher-Timeframe VWAPs

Weekly, Monthly, Quarterly, Yearly VWAP.

Institutions use these to track macro fair price zones.

5. VWAP + Standard Deviations (VWAP Bands)

VWAP can be combined with standard deviation bands (like Bollinger Bands on VWAP).

1σ (first deviation): Intraday range (68% of volume).

2σ (second deviation): Extremes (95% of volume).

3σ (third deviation): Very rare extremes → mean reversion.

Strategies:

Mean Reversion Fade

Long at -1σ / -2σ → Target VWAP.

Short at +1σ / +2σ → Target VWAP.

Trend Continuation

Price holds above VWAP → Buy pullbacks near VWAP / +1σ.

Price below VWAP → Sell rallies near VWAP / -1σ.

Breakout Expansion

VWAP flat → Breakout beyond ±2σ with volume → Ride the trend.

Std Dev Compression → Expansion

Bands narrow → volatility squeeze → breakout coming.

6. Anchored VWAP (AVWAP): Selection & Strategies

How to Select Anchor:

Swing high/low → institutional footprints.

Major event candle → Budget, Fed, Elections, Earnings.

All-time high/low → Long-term zones.

Monthly/Yearly open → Track accumulation zones.

How to Use:

If price bounces repeatedly at AVWAP → confirmation of institutional defense.

AVWAP clusters (multiple anchors overlapping) = strong demand/supply zones.

Swing/positional traders use AVWAP as dynamic stop placement tool.

7. Rolling VWAP Strategies

5D / 20D Rolling VWAP: Institutional bias filter.

If price > rolling VWAP → bullish structure.

If price < rolling VWAP → bearish structure.

Combine with Daily VWAP for short-term alignment with long-term flow.

9. VWAP in Options Trading

Directional Options:

Calls only if price > VWAP.

Puts only if price < VWAP.

Non-Directional / Expiry Day:

VWAP acts like a magnet.

Sell straddles/strangles when price oscillates around VWAP.

Fade ±2σ moves for scalping options.

Theta Plays:

Expiry day → price often returns to VWAP → sell premium away from VWAP.

VWAP + Indicator Frameworks

🔹 VWAP + RSI Divergence

Buy Puts if bearish divergence + rejection from VWAP.

🔹 VWAP + ORB (Opening Range Breakout)

Mark first 15/30-min high & low.

Options angle:

Long ATM puts if breakdown below VWAP & ORL.

🔹 VWAP + CPR (Central Pivot Range)

CPR = Institutional pivot framework.

Confluence: If VWAP aligns with CPR → high-value level.

Options angle:

Straddle selling if CPR narrow + VWAP magnet.

🔹 VWAP + ATR (Stops & Targets)

Use ATR to size stops beyond VWAP/σ band.

If ATR high → breakout trades.

If ATR low → mean reversion.

Options angle:

Low ATR + VWAP fade = option selling.

High ATR + VWAP expansion = option buying.
