Sources & calculation details

{{ snapshot.source }}. {{ snapshot.methodology }}

Charts show up to 90 completed bars; their EMA line is seeded from displayed history and can differ from the full-history trend value. Daily change uses consecutive completed daily closes, even when a newer hourly price is shown. Sutradhar is an intraday reference, not a monthly or weekly signal.

CPR: P = (H + L + C) / 3; BC / TC are the sorted midpoint and reflected midpoint. Camarilla R3 / S3 = C ± range × 1.1 / 4; R4 / S4 = C ± range × 1.1 / 2.
